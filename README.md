# ЦППС | Экзамены курсантов

Веб-портал на Flask + SQLite: регистрация/вход, роли, тесты с четырьмя вариантами, таймер, проходной балл, лимит попыток, история результатов, админ-панель, статистика и назначение стажировок.

## Быстрый запуск на Windows

1. Установите Python 3.11+ с https://www.python.org/downloads/ (при установке включите **Add Python to PATH**).
2. Распакуйте архив в папку.
3. Откройте папку, в адресной строке Проводника напишите `cmd` и нажмите Enter.
4. Выполните:

   ```bat
   py -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   set ADMIN_USERNAME=admin
   set ADMIN_PASSWORD=ChangeThis-Strong-Password-123!
   set SECRET_KEY=replace-this-with-a-long-random-secret
   python app.py
   ```

5. Откройте http://127.0.0.1:5000
6. Войдите как `admin` с паролем, который задали в `ADMIN_PASSWORD`.
7. В админ-панели создайте экзамен, откройте редактор, добавьте вопросы и опубликуйте экзамен.

**Важно:** первый администратор создаётся только если заданы `ADMIN_USERNAME` и `ADMIN_PASSWORD` при первом запуске с пустой базой. Если база уже создана без администратора, удалите `cpps.sqlite3` (это удалит все данные) и запустите приложение заново с переменными окружения.

## Публикация в интернете через Render

Нужен аккаунт Render и GitHub. Я не могу развернуть сайт в вашем аккаунте без вашего входа и разрешений.

1. Создайте GitHub-репозиторий и загрузите в него содержимое этой папки.
2. В Render выберите **New → Blueprint**, подключите репозиторий и подтвердите `render.yaml`.
3. Для `ADMIN_PASSWORD` задайте отдельный длинный уникальный пароль в настройках окружения Render. Не используйте пароль от других сервисов.
4. Дождитесь успешного деплоя и откройте выданный Render URL.
5. Войдите администратором, создайте тест и опубликуйте его.

В `render.yaml` настроен постоянный диск Render (платный план Starter), чтобы SQLite-база не пропадала после перезапусков. Если используете бесплатный хостинг без постоянного диска, локальная SQLite-база может потеряться при redeploy/restart. Для полностью бесплатного постоянного хранения лучше заменить SQLite на управляемый PostgreSQL.

## Возможности и ограничения текущей версии

- Роли: курсант, преподаватель, администратор. Управление ролями выполняет администратор.
- Экзамен: один правильный ответ из четырёх, таймер, автоматическая отправка в браузере и серверная проверка длительности, проходной процент, лимит завершённых попыток.
- Стажировки: создание, назначение по никнейму и статусы «назначена», «в процессе», «завершена».
- Статистика: пользователи, тесты, завершённые попытки, доля успешной сдачи, таблица результатов.
- Защита: хеширование паролей, сессионные cookie, проверка CSRF для POST-запросов, серверная проверка доступа к результатам.

Перед реальным использованием с персональными данными рекомендуется провести аудит безопасности, настроить резервное копирование и мониторинг. В этой стартовой версии роли `teacher` пока не дают отдельной панели управления: создавать тесты и управлять пользователями может только `admin`.
